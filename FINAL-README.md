# LOKYX — Final Functional Demo

This is the final functional frontend build of LOKYX using the supplied gateway assets.

## Run

1. Open this folder in VS Code.
2. Open Terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the localhost URL printed by Vite.

## Included

- Cinematic gateway with supplied background, portal and traveler assets
- Portal entry transition
- Functional navigation and browser history
- Search (Ctrl/Cmd + K)
- Pulse, Traverse, Realms, Districts, Nexuses
- Whispers and notifications
- Arcade demo interactions
- Bazaar and Vault state
- Character and Identity interactions
- Demo Core/wallet interactions
- Companion interactions
- Local persistence for demo state
- Responsive mobile navigation
- Vite + React + TypeScript configuration

## Demo mode

Blockchain, wallet and AI integrations are intentionally simulated locally so the experience works without paid services or external API keys.

## Assets

Place additional LOKYX assets in `public/assets/` and reference them from the UI.
